Как принимается решение

Порядок фиксирован, чтобы бытовые команды не уходили в модель.

1. ТриггерЯвный триггер в тексте сразу отправляет запрос в LLM.
2. Dry-runВ режиме Auto add-on спрашивает у HA intent без выполнения действия.
3. AllowlistЕсли intent разрешён, команда выполняется через Assist.
4. FallbackВсё остальное уходит в выбранную модель с MCP-инструментами.

Инструменты для модели

MCP-серверы дают модели доступ к HA и внешним сервисам.

  • HTTP и SSE подходят для Home Assistant MCP и удалённых серверов.
  • stdio запускает локальный процесс внутри контейнера add-on.
  • Значения заголовков маскируются после сохранения.
  • Недоступный сервер не останавливает остальные.
Пример заголовка: Authorization: Bearer ...
Транспорт: HTTP URL: http://homeassistant:8123/mcp_server/sse
