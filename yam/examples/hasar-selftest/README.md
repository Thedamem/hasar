# Hasar Self Test

Тестовый Lua-пакет для YAM. Ничего не устанавливает и не меняет настройки сам — только проверяет железо по кнопке «Запустить».

## Что делает

1. Кольцо: красный → зелёный → синий → белый.
2. Каждая зона кольца отдельно.
3. Экран: `12:34`, яркость 200, затем выключение.
4. Звук: `tone.wav` из пакета.
5. Возвращает кольцо и экран в штатное состояние.

Громкость не меняется.

## Установка

1. YAM web UI → «Установить .yap» → `hasar-selftest-0.1.0.yap`.
2. Включить пакет.
3. Нажать «Запустить».

Пакет одноразовый (`oneshot`), поэтому после запуска он завершится сам.

## Сборка

```sh
./build.sh
```

Результат: `dist/hasar-selftest-0.1.0.yap`.
